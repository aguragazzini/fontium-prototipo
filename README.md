# Fontium · prototipo

Prototipo de una sola página para probar la idea de Fontium: un diagnóstico corto, un plan paso a paso y asistentes de ejemplo (monotributo, precios, gastos, tiempo, clientes, trámites) para usar la IA en algo concreto de tu vida o tu negocio.

Ver online: https://aguragazzini.github.io/fontium-prototipo/

Es un prototipo: las respuestas de los asistentes son fijas y los datos de monotributo son de ejemplo. No es asesoramiento profesional.
